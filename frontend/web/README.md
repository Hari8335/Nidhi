# Nidhi web

Minimal Next.js App Router foundation with strict TypeScript and Tailwind CSS.
The marketing website, customer application, and admin portal will share this app.
Business logic and authorization belong in the ASP.NET Core API.

From the repository root, run `pnpm install`, then `pnpm dev:web`.
Validate with `pnpm lint`, `pnpm typecheck`, and `pnpm build`.
See the root README for prerequisites and backend commands.
